# Parnika Enterprises Website

A responsive one-page business website for Parnika Enterprises, Indore.

## Files
- `index.html` - website structure
- `styles.css` - responsive design
- `script.js` - mobile menu and year
- `assets/parnika-enterprises-poster.png` - supplied company poster

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish free
This static site can be deployed on GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
